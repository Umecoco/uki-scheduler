# UKI Scheduler

事業説明パネル制作PJ向けの、静的な進捗ダッシュボード試作です。

ブラウザで `index.html` を開くと、内蔵サンプルデータで以下を確認できます。

- 全体進捗率、完了パネル数、遅延タスク数、確認待ちタスク数、今週期限のタスク
- タスクのガントチャート
- クリティカルパス上の危険タスク
- パネル別進捗
- マイルストーン管理
- ブロッカー一覧
- レビュー・承認状況

## CSV読み込み

`sample-schedule.csv` を読み込むと、内蔵サンプルと同じタスクデータで動作確認できます。

タスクCSV列は以下です。

| 列 | 内容 |
| --- | --- |
| `id` | タスクID、またはマイルストーンID |
| `name` | タスク名、またはマイルストーン名 |
| `category` | 企画、文章、素材、デザイン、原稿、レビュー、修正、入稿など |
| `panel` | 対象パネル。複数は `P01\|P02`、全体は `ALL` |
| `start` | 開始予定日。例: `2026-06-03` |
| `end` | 完了期限。例: `2026-09-30` |
| `depends` | 依存タスクID。複数は `T001\|T002` |
| `owner` | 担当者。複数は `designer_a\|designer_b` |
| `reviewer` | 確認者 |
| `status` | 未着手、作業中、確認待ち、修正中、承認済、完了、保留、遅延 |
| `priority` | 優先度 |
| `milestone` | マイルストーンなら `yes` |
| `deliverable` | 成果物 |
| `done_criteria` | 完了条件、または達成条件 |
| `blocker` | ブロッカー |
| `next_action` | 次アクション |
| `updated` | 最終更新日 |
| `impact` | 遅延時の影響 |
| `risk` | リスク |

## パネルCSV

画面右上の `パネルCSV` から、パネル別進捗をCSVとして書き出せます。

| 列 | 内容 |
| --- | --- |
| `panel_id` | パネル番号 |
| `title` | タイトル |
| `message` | 主メッセージ |
| `mockup` | パネル下などに置くモックアップの内容 |
| `designer` | 担当デザイナー |
| `writer` | 原稿担当 |
| `panel_text_status` | パネル掲載文章ステータス |
| `script_status` | 説明原稿ステータス |
| `image_status` | 画像素材ステータス |
| `design_status` | デザインステータス |
| `approval_status` | 承認ステータス |
| `note` | 備考 |
| `blocker` | ブロッカー |

## 現時点の割り切り

タスクCSVは読み込みと書き出しに対応しています。パネルCSVは書き出しに対応していますが、読み込みはまだ未対応です。レビュー・承認管理は、今は画面内蔵のサンプルデータです。
